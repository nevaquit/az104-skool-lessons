The concept

Yesterday you met the 3 device states. Today is the comparison the exam asks about directly: when do you join devices straight to the cloud, and when do you keep 1 foot on-premises?

Microsoft Entra joined means the device is joined directly to the cloud directory. No on-premises Active Directory exists in the picture.

  • Best for: cloud-first organizations, new device fleets, remote workforces.
  • Sign-in: users sign in with their Entra ID credentials and get single sign-on to Microsoft 365 and SaaS apps.
  • Management: Microsoft Intune. Zero-touch provisioning with Windows Autopilot: the user unboxes the laptop, signs in, and policies and apps install themselves.
  • Note: Windows Home edition cannot Entra join. You need Pro, Enterprise, or Education.

Microsoft Entra hybrid joined means the device is joined to on-premises Active Directory and also registered in Entra ID, using device objects synced by Entra Connect.

  • Best for: organizations migrating to the cloud, or ones that still need on-premises AD authentication (file shares, print servers, legacy apps).
  • Sign-in: single sign-on to both on-premises resources and cloud apps, especially when paired with Seamless SSO.
  • Management: Group Policy or Configuration Manager, optionally co-managed with Intune so Conditional Access can still require compliance.
  • Requirement: Entra Connect must be syncing device objects, which is configured during setup.

Microsoft Entra registered (recap from Day 32) is the third option: BYOD. The user adds a work account to a personal device. Light management, no full join.

Side by side:

  • Identity authority: Entra joined is the cloud (Entra ID); hybrid joined is on-premises AD, synced to cloud
  • Needs on-premises AD: Entra joined no; hybrid joined yes
  • Best for: Entra joined suits cloud-first, new fleets; hybrid joined suits migration and on-premises apps
  • Management: Entra joined uses Intune; hybrid joined uses Group Policy / ConfigMgr, optional co-management
  • Provisioning: Entra joined uses Autopilot zero-touch; hybrid joined uses traditional imaging or Autopilot

Key vocabulary

  • Microsoft Entra joined: device joined directly to the cloud directory.
  • Microsoft Entra hybrid joined: device joined to on-premises AD and registered in Entra ID.
  • Seamless SSO: silent sign-on to cloud apps from domain-joined devices on the corporate network.
  • Co-management: a device managed by both Configuration Manager and Intune.
  • Windows Autopilot: zero-touch provisioning: unbox, sign in, configured automatically.

Try it

Read-only. These commands change nothing.

On a Windows 10 or 11 device (your own PC is fine):

  1. Open a command prompt and run dsregcmd /status. Find the 2 lines AzureAdJoined and DomainJoined.
  • AzureAdJoined YES and DomainJoined NO: Entra joined.
  • Both YES: hybrid joined.
  • Both NO with a workplace account present: registered.
  1. Go to Settings > Accounts > Access work or school to see the same state in plain language.

In the portal:

  1. Microsoft Entra admin center > Identity > Devices > All devices. Compare the Join Type column and see if you can spot all 3 states.

Clean up: nothing was changed. dsregcmd only reads status.

Worked example: Meridian Health

Meridian Health is mid-migration, so it uses both:

  • New clinic laptops: Entra joined with Autopilot and Intune. A nurse unboxes 1, signs in with her Entra account, and within minutes it has Wi-Fi profiles, the EHR app, and encryption enforced. No imaging server involved.
  • Hospital workstations tied to on-premises imaging systems that authenticate against Active Directory: hybrid joined. They are managed by Configuration Manager today and co-managed with Intune so the Conditional Access policy requiring compliant devices still applies.

The rule they follow: if the device's apps live in the cloud, Entra join it. If the device still needs on-premises AD every day, hybrid join it until the apps move.

Exam tip

The exam hands you a scenario and expects the join type. "Migrating from on-premises AD" or "must keep single sign-on to on-premises file shares" means hybrid joined. "Cloud only" or "new devices, no on-premises infrastructure" means Entra joined. If hybrid appears, check that Entra Connect device sync is in the picture.

Key takeaways

  • Entra joined: cloud-native, Intune managed, best with Autopilot for new fleets.
  • Hybrid joined: on-premises AD plus cloud registration, for migration and on-premises apps.
  • Registered: BYOD, light management.
  • dsregcmd /status tells you the truth on any Windows device: AzureAdJoined and DomainJoined.
  • Hybrid join depends on Entra Connect syncing device objects.
