The concept

AZ-104 is the Microsoft Certified: Azure Administrator Associate exam. Passing it proves you can run real Azure environments: identities, governance, storage, compute resources, virtual networks, and monitoring.

The exam at a glance:

  • About 40 to 60 questions: multiple choice, case studies, drag and drop, and hot area questions
  • 120 minutes
  • Passing score: 700 out of 1000 (a scaled score, not a flat 70 percent)
  • Cost: about 165 US dollars
  • No official prerequisites, but you will struggle without hands-on time in the portal and the command line

The 5 domains and their weights:

  1. Manage Azure identities and governance: 20 to 25 percent
  2. Implement and manage storage: 15 to 20 percent
  3. Deploy and manage Azure compute resources: 20 to 25 percent
  4. Implement and manage virtual networking: 15 to 20 percent
  5. Monitor and maintain Azure resources: 10 to 15 percent

Identity and compute carry the most weight. Monitoring carries the least, but it still decides pass or fail for many candidates.

The Azure administrator role in real life: you provision and manage identities in Microsoft Entra ID, enforce governance with policy and role assignments, deploy storage and compute, build virtual networks, and keep everything healthy with monitoring and backup. You work in the portal, the Azure CLI, and PowerShell. The exam tests all 3 paths, so this course teaches all 3.

How this course works: 365 days, 1 topic per day. Each day has a 60 second TikTok video, this full lesson, and a hands-on lab. Watch the video, read the lesson, do the lab in your own free Azure account, then answer the check questions. Small daily reps beat weekend cramming.

Key vocabulary

  • AZ-104: the Microsoft Certified: Azure Administrator Associate exam.
  • Microsoft Entra ID: Microsoft's cloud identity service (formerly Azure Active Directory). You will see both names on the exam.
  • Azure portal: the web console at portal.azure.com.
  • Azure CLI: the cross platform command line tool (az). Tested heavily on the exam.
  • Cloud Shell: a free browser based shell in the portal with the Azure CLI and PowerShell preinstalled.
  • Scaled score: the 1000 point scoring scale. 700 to pass does not mean 70 percent of questions answered correctly.

Try it

You need a free Azure account. Create 1 on the Azure free account page if you do not have 1. It includes credits for the first 30 days plus services that stay free for 12 months and longer.

In the portal:

  1. Sign in at portal.azure.com. Use the top search bar: type "Subscriptions" and open it. This search bar is the fastest way to reach any service, and the exam assumes you know it.
  2. Open Cloud Shell from the top toolbar (the >_ icon). Choose Bash or PowerShell when asked and accept the free storage it requests. Cloud Shell itself is free.
  3. In Cloud Shell, run az --version to confirm the CLI works.

In the CLI (Cloud Shell):

  1. List what you can access: az account list --output table. Note the subscription name and which 1 is the default.
  2. Show the current subscription details: az account show --query "{name:name, state:state}" --output table.

Exam tip

AZ-104 tests doing, not memorizing. For every service in this course, learn 2 paths: the portal clicks and the command line. Questions often describe a goal and ask for the fastest way or the least privilege way to reach it. When 2 answers both work, pick the 1 with fewer steps and lower permissions.
