The exam you are preparing for

Microsoft AZ-104: Azure Administrator Associate. It certifies that you can manage Azure in production: identities, storage, compute, networking, and monitoring.

  • Questions: about 40 to 60, including multiple choice, case studies, and drag and drop
  • Time: about 120 minutes
  • Pass score: 700 out of 1000 (scaled, not a raw 70 percent)
  • Cost: about 165 US dollars
  • Prerequisites: none official, but you will struggle without hands-on time in the Azure portal

The exam has 5 domains:

DomainWeight
Manage Azure identities and governance20-25%
Implement and manage storage15-20%
Deploy and manage Azure compute resources20-25%
Implement and manage virtual networking15-20%
Monitor and maintain Azure resources10-15%

Identity and compute are the heaviest. If you are short on time, drill those 2 first. This course follows the same order, so Module 1 starts with identity and governance.

How each lesson works

Every lesson follows the same shape:

  1. Watch (60 seconds): the day's TikTok video. The fast version.
  2. The concept: the full explanation behind the video.
  3. Key vocabulary: the exam terms, defined plainly.
  4. Try it: a hands-on lab. Portal steps first, then the Azure CLI or PowerShell equivalent, because the exam tests both paths. Every lab is free-tier safe and ends with cleanup steps.
  5. Worked example: Meridian Health, a fictional company moving to Azure, applying the concept. You will see them in every module.
  6. Check your understanding: questions to test yourself.
  7. Exam tip: how AZ-104 actually tests this topic.
  8. Key takeaways: the points to remember.

What you need

  • A free Azure account (https://azure.microsoft.com/free). The free tier covers everything in this course.
  • A browser. Most labs also work in Azure Cloud Shell, which needs nothing installed.
  • About 30 minutes per lesson: 1 minute for the video, the rest for reading and the lab.

No prior certification is required. If Azure is brand new to you, the first 2 modules will bring you up to speed before the harder topics land.

The golden rule

Do the labs. AZ-104 is a hands-on exam. Reading about a network security group is worth half as much as creating 1, breaking it, and fixing it. The free tier exists so you can break things safely. Use it.
